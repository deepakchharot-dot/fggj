BIRTHDAY WEBSITE — DEEPAK ❤️

1. Open index.html in Chrome/Edge.
2. The website is responsive for mobile + PC.
3. Main photo and memory photos are already included.
4. To enable "Rose Garden" music:
   - Put your legally obtained audio file in the music folder.
   - Rename it to: rose-garden.mp3
   - Open index.html again.
5. Browsers can block audible autoplay. The site tries autoplay and also starts music on the first tap/click/keypress, with a Play/Pause button always available.

The website is fully local; no server is required.
